# HTML 주요 태그 정리

---

## 1. 문서 기본 구조 태그
* `<html>`: HTML 문서의 최상위(루트) 요소입니다.
* `<head>`: 문서의 메타데이터(제목, 인코딩, 스타일 등)를 포함합니다.
* `<meta>`: 문자 인코딩(`utf-8`), 화면 설정 등 부가 정보를 정의합니다.
* `<body>`: 화면에 실제로 표시되는 모든 콘텐츠를 감싸는 구역입니다.

## 2. 텍스트 및 구분 태그
* `<h1>` ~ `<h6>`: 문서의 제목(Heading)을 나타냅니다.
* `<p>`: 일반 본문 단락(Paragraph)을 정의합니다.
* `<hr>`: 가로 구분선을 그어 주제나 섹션을 분리합니다.

## 3. 목록(List) 태그
* `<ul>`: 순서가 없는 불릿 포인트 목록을 생성합니다.
* `<ol>`: 번호가 붙는 순서가 있는 목록을 생성합니다.
* `<li>`: 목록 내부의 각 개별 항목을 나타냅니다.

## 4. 미디어 및 링크 태그
* `<img>`: 이미지를 출력합니다. (`src`: 경로, `alt`: 대체 텍스트)
* `<a>`: 하이퍼링크를 생성합니다. (`href`: 이동할 URL)

## 5. 표(Table) 작성 태그
* `<table>`: 표 전체를 감싸는 태그입니다.
* `<thead>`: 표의 제목(헤더) 영역을 그룹화합니다.
* `<tbody>`: 표의 본문 데이터 영역을 그룹화합니다.
* `<tr>`: 표의 한 행(Row)을 정의합니다.
* `<th>`: 표의 제목 셀을 나타냅니다.
* `<td>`: 표의 일반 데이터 셀을 나타냅니다.

## 6. 폼(Form) 및 입력 태그
* `<form>`: 사용자 입력을 서버로 전송하기 위한 영역을 감쌉니다.
* `<input>`: 사용자 입력 필드를 생성합니다.
* `<button>`: 클릭 가능한 버튼을 생성합니다.
